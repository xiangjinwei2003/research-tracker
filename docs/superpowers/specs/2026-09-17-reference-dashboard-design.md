# 参考图驱动的任务总览与看板

本规格替代 2026-09-16 的视觉部分；之前已实现的搜索、新建、筛选、完成撤销、拖拽、数据保护等功能继续使用。用户于 2026-09-17 提供两张参考图，明确要求按图设计，同时充分考虑本项目的数据与可视化。代码继续由 GPT 5.6 sol 编写。

## 参考与视觉

- `docs/design-references/2026-09-17-board-light.png`：采用其白色立体卡片、非常浅的列底、细边框、日期标签、优先级图标、卡片底部信息栏、列头计数与快捷添加。
- `docs/design-references/2026-09-17-report-dark.png`：采用其常驻侧栏、紧凑顶工作条、上方统计报告卡与下方看板的组合结构。
- 默认按第一张使用浅色，若用户回复偏好深色则以用户选择覆盖颜色，结构不变。浅色主交互改为参考图的清晰蓝色 #355DF4，前景 #202124，次级 #686B73，页面/列底 #F7F8FA，卡片白色，边框 #E8E9ED。默认参考不再采用森林绿主色。
- 保留真实项目色；语义色为高优先级红、普通优先级橙/蓝、低优先级绿/灰。避免大面积渐变。Logo 同步简洁主色，去除旧紫色深底的不协调视觉。
- 顶工作条 64px 左右，面包屑与当天日期，右侧常驻专注和新建项目。左侧导航及项目入口保留。正文 heading 26px、卡片任务名 15px semibold，元数据 12px。主标题与统计之间紧凑，避免顶部大块留白。

## 信息结构

主区域顺序：标题「任务总览」与简短说明 →「进行中项目概况」四张真实数据统计卡 → 任务看板工具条 → 优先级三列 → 可折叠项目任务池。

统计区是所有进行中项目的概况，不随下方任务文字、项目、范围筛选变化；标题旁明确「全部进行中项目」。看板另显示实际筛选结果数量。专注图标注「全部记录 · 近 7 天」，历史记录保留归档/删除项目的投入。

### 1. 任务概况卡

- 来源：所有 `!project.archived` 的 `project.todos`。
- 显示未完成数、已完成数与逾期未完成数，完成率为 done / total，total=0 时显示「暂无任务」而不是 100%。
- 用已完成/未完成的双段进度条及明确计数，表达当前快照；文案「任务完成比例」，不能称研究进度或按时间的完成趋势。
- 点击未完成切全部待办；点击逾期清除其他过滤并筛选全部项目逾期未完成。

### 2. 项目任务分布卡

- 来源：活动项目各自的未完成任务数。项目色条＋项目名＋件数；以最大值归一化条宽，文本让准确数量可读。
- 显示最多前三项，其他项目汇总为「另 N 个项目 · M 项」，零任务可显示但不可造成假的有值条。
- 点项目行：清除文本、日期和逾期过滤，设置 projectId，切全部待办，查看该项目真实任务。
- 不把研究 stageProgress 的阶段序号冒充百分比完成度。

### 3. 截止日期分布卡

- 来源：活动项目的未完成任务 endDate。今天到 7 天后的八个自然日为八根柱，包含终点，与近期范围一致；过期任务单独计数，未排期任务单独计数，远期不塞进图中。
- 图有真实月日/今天标记、每个柱的 count 与 title/aria-label，不把0绘成有高度的数据柱。柱值只是截止任务件数，不是每日已完成任务。
- 点非零日期柱：清其他过滤、range=all，设置新增 dueDate 精确筛选；工具条显示可清除的「M月d日到期」标签。点逾期与未排期文字也可筛选对应任务（未排期用明确过滤字段，不能用虚构日期）。

### 4. 近七天专注卡

- 来源：已记录 sessions，使用既有 sessionMinutes/dayKey 或同等本地日历口径。过去六天＋今天七根柱，按 startedAt 所在本地自然日归桶；total minutes 为七天各桶之和，排除未来 session。
- 包含自由专注、归档项目与删除项目的历史记录，明确「全部记录」。不把 activeTimer 尚未落盘的计划时长当实际专注。
- 每柱显示日期/分钟数的可访问说明，全部为0时给「近 7 天暂无专注记录」和零基线，不造假数据填图。查看回顾按钮切到已有回顾页。

## 卡片与看板

- 列保持真实 high/normal/low 三档，标题带语义小图标、计数和添加按钮；添加按该列预选优先级。不能照搬参考的 In Progress/Testing，因为当前 Todo 只有 done 布尔值。
- 卡片更接近参考：第一行项目图标/颜色＋名称＋更多；任务标题清楚可点进入编辑；notes 有值才显示两行摘要；阶段与优先级清楚标示；日期置于带日历图标的中性浅底标签。
- 优先级使用类似参考的三个高低条形小图标＋短文本，不能只靠颜色。阶段来自当前任务所属项目的 stage 定义。
- 底部独立细分隔线：左侧显示真实项目合作者的首字/名称（最多三个，其余 +N），title 与 aria-label 写明「项目合作者」，不得冒充任务指派人。无合作者不造头像。
- 右侧显示匹配同一 projectId+todoId 的历史专注分钟数（大于0才显示），并提供始终可见的专注启动按钮。todo.notes 非空可显示备注提示，不显示不存在的评论数、附件数、commit数或关联代码。
- 完成、撤销、优先级菜单、拖拽、pin、快速新建等已实现功能必须保留；移动端和键盘仍可直接操作。
- 卡片自然高度，日期/操作不被长文本挤走。概况区大桌面四列，中屏两列，小屏一列；看板桌面三列、小屏单列，页面单一纵向滚动。
