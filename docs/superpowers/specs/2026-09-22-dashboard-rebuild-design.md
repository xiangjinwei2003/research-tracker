## 视觉规格

- 默认石墨黑，非蓝黑/绿黑。画布 #151517，侧栏 #1c1c1f，卡片 #222225，悬浮 #29292e，线条 #323236。主文本 #f2f2f4，次文本 #aaaab3。数据强调薰衣草紫 #a99af7，高优先级珊瑚 #ef8396，普通紫，低优先级青绿 #78c7b1，今天重点可用杏橙 #efa768。
- 主按钮深色主题为白底深字；浅色主题蓝底白字。功能高亮、焦点圈和数据图用紫色。按钮/菜单/输入/弹窗也必须主题一致，禁止深色表面混入旧浅色药丸。
- 浅色：背景 #fafafb、侧栏 #f5f5f7、白卡片、#e7e7ec 细线、#202126 主字、#707079 次字，轻微双层阴影。参考第二张的白卡片质感，保留同样信息架构。
- 系统无衬线 + 中文系统字体，数字 tabular。页面标题 26px/600，任务名 15px/600，主体 13–14px，辅助12px。无需大面积英文 kicker/渐变/装饰性图形。
- 基础圆角：卡片12px，控件7px，外壳不要额外套大边框。间距8/12/16/24/32。Lucide 16px，统一细线。

## 页面骨架

1440px：224px 固定侧栏、64px顶栏、主区左右32px（宽屏最大1600），内容上间距28px。侧栏和 main/header 使用同一 CSS 变量或相同 rem 断点，避免偏移。768–1099px 68px图标侧栏；<768顶部导航，控件可换行，无整页横向溢出。

侧栏：精炼 logo + Research Tracker / 研究工作台；工作区导航组（看板、日历、专注回顾、归档）；进行中项目列表（真项目色圆点、标题截断、未完成数）；底部数据管理、浅/深主题切换、便签。不要捏造用户姓名/头像/在线同步等。

顶栏：左侧面包屑 工作区 / 当前页，右侧常驻专注计时器和新建项目。计时器始终只有一个挂载实例，切 tab 不应卸载。窄窗口倒计时不设 190px 上限，任务名从 sm 起显示，结束和取消留在胶囊内。标题只有「任务看板」，右侧日期。不写说明句。主新建任务动作放看板工具栏。

概况是一行四个数字按钮：未完成、逾期、今天到期、近 7 天专注。点击前三个会筛选下面的任务列，点击专注进入专注回顾。不在首页放环图、8 日格和柱图。聚合仍用 buildBoardInsights，首页固定取 7 天。

项目区标题为「项目」，默认折叠，只显示进行中数量。展开后才是项目卡。首页不再放第二个「新建项目」。

## 看板与任务卡

工具栏同一行：左侧看板图标+“任务”+结果计数，紧接近期重点/全部待办切换；右侧搜索、项目筛选、逾期过滤、新建任务。必要时拆成两行，筛选后的条件chip与清除出现在下方。默认仍然近期（所有逾期、今天至+7天，另含手动inWeek）。筛选只控制下方看板；上方全局范围有文字标明。

保留真实 **高 / 普通 / 低优先级三列**；项目没有进行中/测试状态，不照抄参考图的虚构状态。列头用优先级图标、标题、紧凑计数、加号。窄窗口一列，中等宽度两列，约 1280px 起三列。断点不和侧栏加宽绑在一起。卡片底栏允许换行。列顶部能清楚读到任务数量。

任务卡完全重新排版：
- 顶行左项目小图标/色点与项目名（截断有全名提示），右三点菜单。
- 任务名从卡片左边缘统一对齐。完成按钮移到标题尾部或底部紧凑控制，不要用大圆形checkbox挤掉标题首列。长标题可3行。
- 若有真实notes显示1–2行次色描述，没notes不要填假说明。阶段在标题下作为安静一行阶段文本/分支小图标。
- 中下行日期pill（逾期珊瑚，今天杏橙）、右优先级短标，手动加入用小pin真实状态。不要堆满彩色badge。
- 底部细分隔线，左项目协作者首字母头像（明确 title/aria 是项目协作者而非任务分配；无则显示项目色点/“独立推进”），右实际累计专注分钟和小型开始专注按钮。不能加假评论/附件数。
- 悬浮细微提亮边框与阴影，不缩放；拖拽时源卡半透明、接收列虚线与淡色高亮。拖拽和键盘菜单改优先级都保留，不能只有装饰。

下方项目任务池作为收纳区，视觉统一但不抢首页焦点。新建/编辑弹窗、时间线、回顾、归档要检查主题兼容，尤其旧硬编码白背景/文本色；不改领域模型。

## 数据与实现边界

- localStorage key/schema7/导入导出/撤销/日期语义不变；不要seed用户数据。
- 可扩展buildBoardInsights：新增优先级计数；可用可选第5参数7|14影响focus聚合，默认7兼容现有测试。today/now明确注入；任务专注历史key仍为JSON(projectId,todoId)。新会话完成必须即时更新统计。
- 主题偏好另用轻量localStorage key；不混进用户项目导出schema。默认dark，主题切换立即生效并持久化；CSS语义tokens统一，硬编码浅色优先级badge改成语义类。
- 显示项目色与阶段色只作身份，不强行重写数据颜色。
- 新建任务、搜索、项目/日期/未排期/逾期联动、完成撤销、drag/drop、菜单变更优先级、开启/结束专注都要可用。
